# Menyona

مشروع منصة مطاعم مُدارة باشتراك، مبنية على WordPress وWooCommerce، مع مواقع مستقلة للمطاعم وتطبيقات Flutter للإدارة والمناديب وقناة مركزية عبر ChatGPT وMCP.

الحالة الحالية: مواصفات وتصميم موثقان. لا يحتوي هذا المستودع بعد على منتج جاهز للتشغيل. اختبارات قبول المتاجر والتطبيقات والدفع والتوصيل وChatGPT غير منفذة.

## شرط الاعتماد الأمني

لا تعتمد أي جزئية قبل موافقة وكيل المراجعة الأمنية المستقل واجتياز اختباراته اللازمة للنسخة نفسها. راجع [القرار الحاكم للمراجعة الأمنية](SECURITY_REVIEW_POLICY.md) و[تعليمات المساهمين والوكلاء](AGENTS.md).

نشر هذه الوثائق لا يثبت قبول المنتج أمنيًا أو جاهزيته التجارية. تنفيذ CI وحماية الدمج وربط المراجعة موثق في [CI_AND_SECURITY.md](CI_AND_SECURITY.md)، بما فيه الحالة الفعلية وأدلة القبول وحدود حساب المراجع.

فُعّل CI وحماية main، ونجحت اختبارات منع محددة على GitHub. ما زال اختبار مسار الموافقة والدمج كاملًا محجوبًا بإعداد المنظمة؛ التفاصيل في [تقرير التنفيذ](CI_EXECUTION_REPORT.md).

## نطاق المنتج

فرع واحد لكل اشتراك، وثلاثة أشكال للقالب، وقائمة وطلبات عبر QR مستقل للطاولة، وحجوزات بمخطط وبديل نصي، واستلام عند الباب أو السيارة، وثلاثة نماذج للتوصيل. تطبيق إدارة موحد على Android وiOS وWindows، وتطبيق مناديب على Android وiOS.

البداية السعودية ثم مصر ثم بقية الخليج. أموال المطعم وحساب بوابته وعلاقته بمزودي الدفع والتوصيل له. قواعد الإتاحة لقارئ الشاشة ولوحة المفاتيح وعزل بيانات المطاعم شروط قبول، وليست خصائص مثبتة قبل التنفيذ.
